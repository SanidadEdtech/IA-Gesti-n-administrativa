# Gestión administrativa sanitaria con IA

Contenido interactivo sobre los fundamentos de la gestión administrativa sanitaria con inteligencia artificial.

> **EN** · Interactive learning resource on healthcare administration with artificial intelligence.

🔗 **Demo:** [iaengestion.sanidadedtech.es](https://iaengestion.sanidadedtech.es/)

## Para quién es

Alumnado de T.S. en Documentación y Administración Sanitarias.

## Qué incluye

- Arquitectura Data Lakehouse
- MLOps y Feature Store
- RGPD y Reglamento de Inteligencia Artificial
- Privacidad avanzada

## Tecnología

- Página única en HTML, CSS y JavaScript, sin frameworks ni proceso de compilación.
- Diseño adaptable a móvil.
- Publicado con GitHub Pages.
- Desarrollado mediante *AI-driven prototyping*: diseño pedagógico y clínico propio, construcción asistida por IA y revisión manual.

## Uso

Abre la demo en el navegador o descarga `index.html` y ábrelo directamente: no necesita instalación.
